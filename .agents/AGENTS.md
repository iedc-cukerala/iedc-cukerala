# IEDC Official Website Rules

- **Custom Domain Future-Proofing:** The user plans to attach an official custom domain to this Firebase hosting project in the near future. Ensure all routing, asset linking, and API calls are strictly relative and domain-agnostic. Avoid hardcoding `iedc-cuk.web.app` in any logic, with the exception of Open Graph tags (which will be updated once the final domain is acquired).
